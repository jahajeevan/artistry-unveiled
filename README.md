# Artistry Unveiled

A refined digital experience for **Maison Lumière**—a visual portfolio that presents creative work through an editorial, image-led interface.

## Built with

- React and TypeScript
- TanStack Start and Vite
- Tailwind CSS

## Run locally

```bash
bun install
bun run dev
```

Create a production build with `bun run build`.
